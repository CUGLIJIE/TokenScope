TokenScope показывает расход токенов нескольких аккаунтов Codex и Claude Code в Windows. Локальная панель выбирает язык из настроек браузера. Если подходящего языка нет, используется английский. Выбор в меню **Язык** сохраняется.

- **Облачные данные Codex.** Установленный клиент Codex использует ваш вход в ChatGPT, чтобы получить общий расход по аккаунту и, при наличии, данные по дням.
- **Локальные данные.** Журналы сеансов и импорт файлов JSON/CSV позволяют посмотреть входные, выходные и кешированные токены по моделям. Облачная и локальная статистика учитываются отдельно, чтобы избежать двойного подсчёта.

## Быстрый запуск

Установите Python 3.10 или новее для Windows и выполните команду в PowerShell из папки проекта:

```powershell
.\start.cmd
```

Панель откроется по адресу `http://127.0.0.1:8765`. Если клиент Codex не найден, появится ссылка на установку приложения ChatGPT для Windows. Статистика хранится в локальной базе SQLite.

Чтобы попробовать без входа, импортируйте [usage.json](../../examples/usage.json) в разделе **Аккаунты и данные**. Затем выберите **Локальные и импортированные → Все даты**.

## Тесты и сборка

В автономный архив исходников для Windows x64 входят Python и средства сборки. После распаковки скрипты запускаются без установки и загрузки зависимостей.

```powershell
.\test.cmd
py -3 -m pip install PyInstaller==6.21.0
.\build.cmd
```

После сборки исполняемый файл для Windows будет доступен по пути `dist\TokenScope.exe`.
